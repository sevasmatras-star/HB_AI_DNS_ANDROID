# HB AI Smart DNS для Android

**HB AI Smart DNS** — неофициальный Android-порт проекта [neiroseti-ai/hb-ai-xbox-dns](https://github.com/neiroseti-ai/hb-ai-xbox-dns). Приложение позволяет переключать Smart DNS-профили для проверки доступности зарубежных AI-сервисов, в том числе ChatGPT, Claude, Gemini и ElevenLabs.

> Важно: Smart DNS не является полноценным VPN. Он может помочь только с ограничениями, которые обходятся изменением DNS/маршрутизацией отдельных доменов на стороне DNS-провайдера. Он не гарантирует обход DPI, IP-блокировок, геоограничений, авторизационных проверок или ограничений самого сервиса. Результат зависит от провайдера, сети и актуальности DNS-профиля.

## Возможности

- Выбор профиля Comss.one, GeoHide EU, MagicDNS или Xbox DNS.
- Подключение и отключение локального DNS-туннеля через системный `VpnService`.
- Проверка ответа основного и резервного DNS-сервера.
- Переключение на резервный сервер, если основной не отвечает.
- Сохранение последнего выбранного профиля.
- Тёмный интерфейс на русском языке.

## Совместимость

- Минимальная версия: **Android 12 (API 31)**.
- Целевая версия сборки: **Android 15 (API 35)**.
- Сборка использует Android Gradle Plugin 8.7.3, Kotlin 2.0.21 и JDK 17.

## Установка и использование

1. Установите APK, собранный из этого проекта.
2. Откройте приложение и выберите DNS-профиль.
3. Нажмите **«Подключить Smart DNS»**.
4. Подтвердите системный запрос Android на создание VPN-подключения. Это локальный интерфейс `VpnService`, необходимый Android для перехвата DNS-пакетов; приложение не поднимает удалённый VPN-сервер.
5. Для прекращения работы нажмите **«Отключить и вернуть обычный DNS»**.

Если DNS не работает, временно отключите Android «Частный DNS» (Настройки → Сеть и интернет → Частный DNS), другие VPN-приложения и сетевые фильтры. После тестирования включите нужные настройки обратно.

## Технические ограничения текущей версии

Это ранняя реализация Android-порта, а не полная копия функций Windows/macOS:

- Локальный перехватчик обрабатывает **UDP DNS по IPv4 и IPv6** (для IPv6 без extension headers).
- Если upstream DNS вернул усечённый UDP-ответ с флагом TC, приложение повторяет запрос к upstream-серверу по **TCP DNS**. Это TCP fallback между приложением и DNS-провайдером.
- **Клиентские DNS-запросы, изначально отправленные приложением телефона по TCP/53, пока не перехватываются**. Это отдельная часть TCP-прокси, которая требует полноценного TCP state machine; не следует считать поддержку TCP DNS полной.
- IPv6 extension headers, фрагментация IP и DNS-over-TLS/HTTPS (DoT/DoH) не обрабатываются.
- Проверка в приложении подтверждает только получение DNS-ответа от IP-адреса. Она **не проверяет**, открывается ли ChatGPT, Claude, Gemini или ElevenLabs и не определяет капчу/геоблокировку.
- Добавлен ручной автоподбор по времени DNS-ответа для профилей, кроме Xbox DNS. Это не гарантирует, что выбранный профиль обходит нужную блокировку.
- Добавлена проверка DNS-ответов для доменов ChatGPT, Claude, Gemini и ElevenLabs. Она проверяет только DNS-разрешение, а не доступность сайта, вход в аккаунт или снятие блокировки.
- Некоторые Android-устройства, прошивки, Private DNS, VPN и сетевые фильтры могут конфликтовать с `VpnService`.
- Адреса DNS могут изменяться или переставать отвечать. Перед распространением APK проверяйте их актуальность и условия соответствующих провайдеров.

## Сборка APK

### Через Android Studio

1. Откройте папку проекта в Android Studio.
2. Установите JDK 17 и Android SDK Platform 35.
3. Дождитесь завершения Gradle Sync.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Debug APK появится по пути `app/build/outputs/apk/debug/app-debug.apk`.

### Через GitHub Actions

В репозитории уже добавлен workflow `.github/workflows/android.yml`. После отправки проекта в GitHub:

1. Откройте вкладку **Actions**.
2. Выберите workflow **Build Android APK**.
3. Нажмите **Run workflow** (или отправьте commit в `main`).
4. После успешного выполнения скачайте артефакт `HB-AI-Smart-DNS-debug-apk`.

Debug APK предназначен для тестирования. Для публикации в Google Play или распространения как релизной версии настройте release-подпись и храните ключ подписи вне репозитория.

## Проверки

В репозитории настроена CI-сборка Gradle. Перед выпуском APK дополнительно протестируйте на реальном устройстве:
- запуск и остановку VPN-сервиса;
- DNS-запросы по Wi-Fi и мобильной сети;
- переключение между всеми профилями;
- работу при включённом/выключенном Private DNS;
- восстановление обычного соединения после остановки приложения.

**Статус проверки в этой среде:** исходники и конфигурация проверены статически; полноценная Android-сборка и тест на физическом устройстве здесь не выполнялись, поскольку в среде нет Android SDK/Gradle и нет доступа к загрузке зависимостей. Не считайте проект уже протестированным релизом.
